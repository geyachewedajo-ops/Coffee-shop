☕ Wedajo Coffee Shop

A responsive coffee shop web application built with modern web technologies. Customers can browse the menu, add products to their cart, and place orders. An admin interface is included for managing orders.

📸 About the Project

Wedajo Coffee Shop is a full-stack web development project created to demonstrate skills in frontend development, backend API design, database integration, and responsive web design.

✨ Features

- Responsive design for mobile and desktop devices
- Coffee shop menu with product prices
- Shopping cart functionality
- Order submission through a backend API
- Admin authentication
- Admin order management
- REST API integration
- MongoDB database integration

🚀 Getting Started

1. Clone the Repository

git clone https://github.com/geyachewedajo-ops/coffee-shop.git
cd coffee-shop

2. Install Frontend Dependencies

npm install

3. Start the Frontend

npm run dev

4. Run the Backend

Open a separate terminal, navigate to the backend directory, and install the backend dependencies:

cd backend
npm install
node server.js

Configure the required environment variables before starting the backend. Do not upload passwords, database credentials, JWT secrets, or ".env" files to GitHub.
